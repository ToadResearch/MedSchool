Inside the FHIR server: 
    resources point to each other by the server’s logical id
    (Patient/{id} like Patient/1206).

At the enterprise level: 
    humans are identified by business identifiers 
    (MRN, enterprise ID from the MPI/EMPI, national IDs, etc.) 
    that live in Patient.identifier.

----------------------------------------------------------------------------

when using server-assigned logical id: GET [base]/Patient/1206

  {
    "path": "Encounter?patient=Patient/1206&date=ge2024-09-05"
  }

always start with something like 

    "get the logical id for patient with mrn/identifier 119e46a1-9323-916b-4152-e0daedb48f23"


----------------------------------------------------------------------------
to get info about a patient:

    using server logical id returns the Patient resourceType with matching id:
        "GET [base]/Patient/1206"

                        {

                        "id": "1206",
                        "meta": {

        "GET [base]/Patient?identifier=119e46a1-9323-916b-4152-e0daedb48f23"
